Interaction & Controls

상태 위계와 control semantics를 실제 브라우저에서 비교하기 위한 테스트 페이지입니다.

Button hierarchy

Primary는 현재 scope의 핵심 action 하나에만 제한적으로 사용합니다.

Focus-visible

Selected와 독립된 2px blue-700 외곽 ring을 사용합니다.

실제 키보드 Tab 이동으로도 focus-visible 상태를 확인하세요.

Segmented control

같은 데이터의 표시 mode를 바꿀 때 사용합니다.

Filter chips

데이터 subset을 변경하며 multi-select 여부를 명확히 정의합니다.

Tabs

서로 다른 view/section을 이동할 때 사용하며 Segmented와 구분합니다.

Select / Date / Icon
