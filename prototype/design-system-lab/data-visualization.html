DESIGN SYSTEM LAB

Data Visualization

같은 Axis·Legend·Tooltip이라도 분석 질문에 따라 달라져야 하는 경우를 한 화면에서 비교합니다. 수치는 모두 시각 문법 검증용 dummy data입니다.

CASE 01 · SINGLE TREND

단일 시계열 · Full magnitude

한 series이므로 legend를 제거하고 끝점 direct label을 사용합니다.

Overview에서는 실제 규모를 함께 읽게 하기 위해 zero 포함을 기본으로 둡니다.
CASE 02 · FOCUSED TREND

단일 시계열 · Focused domain

변화 방향이 핵심인 상세 분석에서는 line chart에 한해 non-zero domain을 허용합니다.

Bar처럼 길이 자체가 규모를 뜻하는 chart에서는 이 방식 사용 금지. Detail에서만 허용합니다.
CASE 03 · MULTI SERIES

4-series 추이 · Legend + 선택 강조

직접 라벨 충돌 가능성이 높은 경우 top legend를 쓰고, 선택 시 다른 series는 identity를 유지한 채 mute합니다.

CASE 04 · INDEXED COMPARISON

플랫폼별 상대 성장 · Baseline 100

절대 규모가 다른 플랫폼의 성장 궤적을 비교할 때 raw value 대신 index를 사용할 수 있습니다.

Tooltip에서는 index뿐 아니라 원 값도 같이 보여주는 것을 권장합니다. Baseline 정의는 반드시 화면에 명시합니다.
CASE 05 · ABSOLUTE BAR

절대 비교 · Zero baseline

Bar의 길이가 값 자체를 의미하므로 numeric axis는 반드시 0에서 시작합니다.

CASE 06 · LONG LABEL RANKING

긴 한국어 제목 · Horizontal ranking

긴 곡명은 x-axis를 억지로 회전시키기보다 horizontal bar/list로 전환합니다.

CASE 07 · MISSING / ESTIMATED

Missing ≠ Zero

실제 누락은 line break, 실제 추정값만 dashed segment로 표시합니다.

데이터가 없는데 선을 연결하면 실제 관측된 변화처럼 오해될 수 있으므로 기본 금지합니다.
CASE 08 · SIGNED DELTA

증감 비교 · Zero reference

양/음 방향을 zero line에서 갈라지게 하며, 증가/감소만으로 green/red 평가를 부여하지 않습니다.

CASE 09 · EVENT ANNOTATION

이벤트 annotation · Single / Cluster

이벤트는 원인 설명이 아니라 사실적 시간 맥락입니다. 밀도가 높으면 cluster 또는 별도 lane으로 이동합니다.
